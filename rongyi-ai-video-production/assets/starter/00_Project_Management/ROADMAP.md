# Roadmap

## Phase 1: MVP pipeline

**Goal:** Human recorded video -> FFmpeg -> Remotion -> final MP4.

Exit when one representative recording completes this path and passes technical and creative review.

Phase 1 also establishes the minimum approved `script.md`, versioned `job.json` contract and validation, normalized presenter profile, and repeatable render command needed to reproduce that result.

## Phase 2: Automatic subtitles

Add repeatable transcription, timing, styling, and multilingual typography after the MVP render path is stable.

## Phase 3: AI Digital Twin integration

Add provider-specific generation and normalization so a digital-twin source enters the same Remotion and FFmpeg post-production path as human footage.

## Phase 4: Codex automation workflow

Add safe Codex commands, batch orchestration, run manifests, migration tools, expanded tests, and repeatable project-maintenance workflows on top of the Phase 1 Production Job contract.

## Phase 5: Commercial production system

Add team collaboration, rights gates, reusable brand templates, release controls, analytics, and scalable multi-platform delivery.
